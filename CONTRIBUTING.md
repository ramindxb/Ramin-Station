# Contributing

Bug reports and focused pull requests are welcome. Before opening an issue:

1. Install the latest release.
2. Run **Setup / Update** inside Ramin Station.
3. Reproduce the problem without including private URLs, cookies, or personal media.

For a useful bug report, include the operating system, Ramin Station version, selected mode and quality, and a redacted copy of the terminal error.

By submitting a pull request, you confirm that you have the right to submit the contribution and agree that the project owner may distribute it as part of Ramin Station under the project's current license.
