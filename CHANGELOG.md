# Changelog

All notable changes to Ramin Station are documented here.

## 2.0.0 — 2026-10-12

- Added Visual Brain with a three-slot Motivation deck, categorized reference library, drag-and-drop media and links, notes, search, reordering, and right-click deletion.
- Added persistent Visual Brain state storage to the native macOS and Windows wrappers.
- Added a dedicated top drag strip and reliable native window dragging.
- Replaced the macOS and Windows application icons with the supplied Ramin Station icon.
- Expanded the home deck with a third Visual Brain key.
- Made the Ideas library the main section, moved Motivation to the top, and moved Keep the Spark to the bottom.
- Enlarged library cards and file text and added searchable custom client hashtags.
- Added managed file copies for new Visual Brain imports and reveal actions for Finder and Explorer.
- Added background downloads on saved link cards, inline progress, and conversion into local-file cards on completion.
- Updated the home subtitle to MEDIA TOOLKIT V2 and desktop package versions to 2.0.

## 1.0.0 — 2026-08-25

### Added

- Native macOS and Windows desktop applications.
- MP4 video and MP3 audio downloads powered by yt-dlp.
- Public, browser-cookie, automatic retry, and `cookies.txt` access modes.
- Direct output to the user's Downloads folder.
- Single-file and full-folder HEVC/H.265 compression.
- High, Balanced, and Tiny compression presets.
- ProRes Proxy MOV output through Decompress / Edit Fast.
- Live terminal logs, progress bars, and cancellation.
- Native clipboard paste and desktop window controls.
- Automatic setup and update of FFmpeg, yt-dlp, and Deno.
- Ramin Station application icon and branded tactile interface.
