# Ramin Station v2.1

- Optional automatic playable copies in Download and Visual Brain. Originals are always kept.
- Lossless stream copying when possible; high-quality H.264 copies when needed, with compatible original audio copied unchanged.
- Existing library clips can be repaired with **Make playable copy**, without re-downloading.
- Managed-file video/audio previews now load directly from the app's library folder.
- Quiet in-app update checks: a native File menu entry on macOS, a small corner menu on Windows, and an availability notice only when a verified newer build exists.
- Signed update metadata and package integrity checks; staging, library-index backup, restart and failed-start rollback.
- Updated interface version label: **MEDIA TOOLKIT V2.1**.
- Five responsive square Motivation tiles, with optional full-screen media previews and no stretched portrait videos.

Visual Brain files, categories, notes and hashtags stay in the same per-user data folder.
Existing v2.0 users need to install v2.1 manually once to receive future in-app updates.

Codec re-encoding is not mathematically lossless. HDR/wide-gamut sources that would require SDR conversion are retained with a warning rather than silently changing their colors.
This personal release is not Apple-notarized or Microsoft publisher-signed; OS trust warnings may still appear.
