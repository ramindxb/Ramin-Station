# Ramin Station 2.0.0

Version 2 adds Visual Brain: a local library for the references, clips, music, and ideas you want to find again.

## What's new

- A third home key opens Visual Brain.
- Three pinned Motivation items sit above a larger Ideas library.
- Organize references by Instagram, YouTube, Music, or Other.
- Add editable notes and searchable custom client hashtags.
- Drag and drop media or links, reorder cards, and right-click to move or remove them.
- Newly imported media is copied into Ramin Station's managed files folder. Reveal a copied file in Finder or Explorer from its card.
- Saved links have a temporary Download button with inline progress. Downloads run in the background and completed links become local-file cards.
- Move the app using the black drag strip at the top of every screen.
- Updated macOS and Windows app icons and MEDIA TOOLKIT V2 branding.

Download, HEVC compression, and ProRes Proxy / Edit Fast remain available, along with app-managed FFmpeg, yt-dlp, and Deno setup.

## Packages

- `Ramin-Station-2.0-macOS.dmg` — universal macOS installer image, Apple Silicon and Intel, macOS 13+.
- `Ramin-Station-2.0-macOS.zip` — zipped macOS application.
- `Ramin-Station-2.0-Windows-Setup.exe` — Windows x64 per-user installer.
- `Ramin-Station-2.0-Windows-Portable.zip` — portable Windows x64 application.
- `SHA256SUMS.txt` — package integrity checksums.

## Platform notes

This release is not signed with an Apple Developer ID or a Windows code-signing certificate. The macOS app was launched and its packages were verified locally. Windows packages were cross-compiled and checked for integrity; Windows runtime testing is still pending.

Local Visual Brain data stays on your computer. Regular Download-deck jobs save to Downloads; Visual Brain downloads save in its managed library folder.
