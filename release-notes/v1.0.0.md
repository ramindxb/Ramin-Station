# Ramin Station 1.0.0

The first desktop release of Ramin Station brings the tactile retro media deck to macOS and Windows.

## Highlights

- Download video or audio with selectable quality.
- Retry protected YouTube links using browser cookies or `cookies.txt`.
- Compress a single video or an entire folder to HEVC/H.265.
- Convert footage to ProRes Proxy MOV for smoother editing on slower systems.
- Install and update FFmpeg, yt-dlp, and Deno from inside the app.
- Follow every job through live logs and progress, with a dedicated Cancel control.

## Packages

- `Ramin-Station-1.0-macOS.dmg` — macOS installer image.
- `Ramin-Station-1.0-macOS.zip` — zipped macOS application.
- `Ramin-Station-1.0-Windows-Setup.exe` — Windows per-user installer.
- `Ramin-Station-1.0-Windows-Portable.zip` — portable Windows application.
- `SHA256SUMS.txt` — integrity checksums for every package.

## Unsigned build notice

This personal V1 release is not signed with an Apple Developer ID or a Windows code-signing certificate. macOS may require Control-click → Open, and Windows SmartScreen may show Unknown Publisher.
