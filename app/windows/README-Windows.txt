RAMIN STATION 2.1 — WINDOWS

PORTABLE
Run "Ramin Station.exe" directly. No installation is required.

SETUP
The Setup version installs the app for the current Windows user and creates a Start Menu shortcut. It does not need administrator access.

FIRST USE
Open Download or Compress, then press SETUP / UPDATE. The app downloads verified copies of FFmpeg, ffprobe, yt-dlp and Deno into its private tools folder.

PRIVATE LINKS
For media that requires your existing login, select Chrome, Edge or Firefox Cookies. Close the selected browser first if it locks its cookie database.

SECURITY NOTE
This friends-only build is not digitally signed. Windows SmartScreen may show an Unknown Publisher warning.
