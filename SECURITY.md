# Security

## Reporting a vulnerability

Please do not publish secrets, browser profiles, cookie files, private download URLs, or personal media in a public issue.

For a security-sensitive report, use the contact link at [raminpiri.ir](https://raminpiri.ir/) and include only the minimum information needed to reproduce the problem.

## Cookie files

A `cookies.txt` export grants access to the same authenticated session as the browser account it came from. Treat it like a password:

- Keep it on your own device.
- Never attach it to an issue or log.
- Delete it when it is no longer needed.
- Sign out of affected sessions if it is exposed.

Ramin Station passes the selected cookie file directly to yt-dlp. It does not upload the file to a Ramin Station server.
